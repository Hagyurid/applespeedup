# 에쁠가속기 / A+ Accelerator

과목별 강의자료와 정리본을 관리하는 [비공개 Sites](https://aplus-accelerator.astralsmile8.chatgpt.site) 프로젝트입니다. 개발 소스는 [Hagyurid/applespeedup의 `develop/aplus-v2`](https://github.com/Hagyurid/applespeedup/tree/develop/aplus-v2)에 있습니다. `Hagyurid/study`는 읽기 전용 참고 저장소입니다.

사이트는 자료의 등록·검색·편집·저장을 담당합니다. AI의 OCR, 전사본 교정, 목차·정리본·문제팩 생성은 설치된 **에쁠가속기 ChatGPT 플러그인**을 사용자가 대화에서 실행할 때 이뤄집니다. 별도 OpenAI 모델 API 키와 Render를 사용하지 않으며, Render 자료도 가져오지 않습니다. 음성 파일 업로드나 음성 전사 기능은 없습니다.

## 사용 흐름

1. 사이트의 **강의 관리**에서 과목을 만들고 특성을 입력합니다.
2. **강의자료**에서 TXT/MD 전사본 또는 PDF·이미지를 등록합니다. 현재 강의 주차와 과거 기출 연도는 사용자가 지정합니다. PDF는 업로드한 기기의 PDF.js가 페이지 이미지와 추출 가능한 문자 정보를 D1/R2에 준비합니다. 준비가 중단되면 같은 자료에서 이어할 수 있습니다.
3. 사이트의 **GPT 원문 검토 요청**을 ChatGPT에 붙여넣고 플러그인으로 페이지 이미지를 판독합니다. 전사본은 텍스트 원문을 확인합니다. 교정본·근거·미확인 항목을 페이지마다 저장한 뒤 전체 검토를 완료합니다. 손글씨나 수식의 무오류 판독은 보장하지 않습니다.
4. **GPT 작업**에서 검토 완료한 자료를 선택하고 요청문을 복사합니다. GPT는 선택한 교정본만 읽어 목차를 먼저 저장하고, 절마다 정리본과 버전 이력을 저장합니다. 작업 목록에서 저장 상태를 확인하고 이어할 수 있습니다.
5. **정리본**에서 원문을 편집하거나 문서 미리보기·PDF 인쇄·이전 버전 가져오기를 사용합니다. 이전 버전은 편집기에 가져온 후 저장하면 새 버전이 됩니다. **문제풀이**에서는 문제팩의 답·필기·오답·북마크를 사용자별로 저장합니다. **CASIO**에서는 Blueprint·PRGM 텍스트·설명서를 보관합니다.

## 저장과 권한

Sites의 확인된 로그인 사용자 ID를 서버에서 사용합니다. 과목·자료·정리본·작업·문제팩·개인 풀이마다 서버가 권한을 확인합니다. 사이트 접근 범위는 소유자 전용입니다. D1은 메타데이터·교정 페이지·정리본·작업·풀이를, R2는 업로드 원본과 PDF 페이지 이미지를 보관합니다. 수정에는 버전 충돌 검사를 적용하고 신규 정리본 재전송은 요청 ID로 중복 생성을 막습니다.

## 개발 검사

`pnpm install --frozen-lockfile` 후 `npm run check`, `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test:worker`를 실행합니다. Worker 통합 테스트는 로컬 Workerd의 D1/R2와 시험용 인증 헤더를 사용합니다. 이는 실제 로그인·실제 기기 펜 입력 검사를 대신하지 않습니다.

## 범위와 제한

- DOCX/PPTX는 원본을 보관할 수 있지만 본문 판독·검토 완료 흐름이 없습니다. PDF, TXT/MD, PNG/JPG를 OCR·교정 대상으로 사용하세요.
- CASIO 코드를 계산기에서 실행·검증하거나 ZIP으로 내보내지는 않습니다. Word 문서 내보내기도 제공하지 않습니다.
- 사이트의 자료 등록은 ChatGPT OCR을 자동으로 시작하지 않습니다. 검토 요청을 ChatGPT에서 실행해야 합니다.
- 실제 사용자의 자료가 없는 빈 과목 DB에서는 플러그인의 교정본 쓰기와 이미지 읽기 실사용 결과를 확인할 수 없습니다. 자동 검사와 실제 플러그인 검사는 구분해 기록합니다.

현재 구현 상태와 검증 근거는 [v0.11 기록](docs/V11_IMPLEMENTATION_STATUS.md), GPT 절차는 [GPT 워크플로](docs/GPT_WORKFLOW.md)를 참고하세요.
