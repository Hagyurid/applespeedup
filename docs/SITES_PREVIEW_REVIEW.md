# 에쁠가속기 v0.7.0-preview.1 검토 결과

2026-10-08 · 개발 대상 `Hagyurid/applespeedup` / `develop/aplus-v2`

## 현재 판정

**Sites 프로젝트 등록 및 배포 가능한 검토 소스 준비. 사용자에게 열리는 미리보기 URL은 아직 발급하지 않았습니다.**

Sites는 비공개 URL도 배포로 취급합니다. 실서비스 배포를 승인 후 진행하라는 요청에 따라, 소스와 빌드 결과를 먼저 저장하고 배포 호출은 보류합니다. 관리되는 내부 미리보기는 외부 검토용 URL이 아닙니다.

| 항목 | 상태 | 검증 범위 |
|---|---|---|
| Sites 프로젝트 | 등록 완료 | 본인만 접근 가능한 기본 접근 정책 확인 |
| 공식 Sites 구조 | 준비 완료 | Vinext/Vite, Worker ESM, hosting.json, Drizzle 마이그레이션 |
| 기존 UI 재사용 | 구현 완료 | `web/connected.html`을 인증된 홈 화면에서 재사용, 로컬 데모는 별도 보존 |
| D1 및 R2 연결 | 로컬 Worker 검증 통과 | 실제 workerd 런타임과 로컬 D1/R2 에뮬레이션. 운영 리소스 연결은 배포 후 확인 필요 |
| Sites 인증 어댑터 | 구현 및 로컬 테스트 통과 | Sites가 제공하는 검증된 ID·이메일 헤더 사용. 실제 ChatGPT 로그인 왕복은 미검증 |
| 사용자별 읽기·쓰기 | 자동 테스트 통과 | 타인 과목·강의·자료·파일·정리본 접근 차단, viewer 쓰기 차단 |
| 새 빈 데이터베이스 | 초기 마이그레이션 준비 | 강의·자료·정리본을 넣는 seed 및 기존 Render 데이터 이관 없음 |
| 중복 저장 방지 | 자동 테스트 통과 | 사용자별 과목, 학년도·교수·분반, 강의별 동일 파일/텍스트, 정리본 생성 요청 |
| 수정 충돌 방지 | Worker 동시 수정 검증 통과 | 동시에 같은 버전을 수정하면 한 요청만 성공, 나머지는 409 |
| 정리본 버전 | 저장 구현 및 테스트 통과 | 본문 조회·수정 및 버전 스냅샷. 버전 복원 UI는 아직 없음 |
| PDF 페이지별 추출 | 미완료 | PDF 원본 보관 및 다운로드만 가능. 추출 상태 `pending` |
| GPT 작업 상태·이어하기 UI | 미완료 | 기존 서버 작업 코어 보존, 웹의 요청문 복사 기능만 제공 |
| 전용 ChatGPT 플러그인 | 미완료 | 기존 MCP 코어/Skill 보존. 현재 사이트 `/mcp`는 503으로 잠금 |
| 브라우저 사용 테스트 | 미실시 | 현재 세션에 필요한 브라우저 제어 스킬이 없어 클릭·화면·모바일 검증을 진행하지 못함 |
| 운영 URL·실제 로그인·실제 서버 저장 | 미검증 | 배포 승인 및 첫 로그인 확인 필요 |

## 변경 내용

- `.openai/hosting.json`에 기존 스키마와 호환되는 논리 바인딩 `DB`와 `BUCKET` 지정. Cloudflare 운영 리소스는 Sites가 배포할 때 연결합니다.
- `db/schema.ts`와 생성된 `drizzle/` SQL을 운영 스키마의 기준으로 사용합니다. `sites/schema.sql`은 Node/SQLite 테스트용 자동 생성 사본입니다. 요청 처리 중 테이블을 생성하지 않습니다.
- `sites/auth.mjs`에서 Sites의 `oai-authenticated-user-id` 및 `oai-authenticated-user-email`을 사용합니다. 본문·임의 `x-user-id`·모델 API 키·서비스 우회 토큰을 사용자 신원으로 사용하지 않습니다.
- `sites/runtime.mjs`를 Worker 진입점에 연결했습니다. 사용자별 인가를 기존 리포지토리에서 다시 검사하고, 파일은 권한 검사 후 다운로드합니다.
- 최초 운영 배포는 **자료 변경 잠금 상태**입니다. `APLUS_WRITES_ENABLED`는 기본값과 Sites 설정 모두 `false`이며, 실제 로그인·접근 경계 확인 전에는 자료 변경을 허용하지 않습니다. 호출자가 헤더나 JSON으로 잠금을 해제할 수 없습니다.
- 같은 과목/강의 및 동일 내용 업로드는 기존 레코드를 재사용합니다. 텍스트 청크 생성 중 과학 표기와 위첨자를 변형하지 않습니다.
- 강의를 바꾸면 해당 강의의 작성 중 자료와 정리본을 복원합니다. 강의 전환 중 로딩이 실패해도 이전 강의의 자료 목록을 새 강의 아래 표시하지 않습니다. 초안은 현재 탭 메모리에만 보관되며 영구 저장본은 D1을 기준으로 합니다.
- 정리본 신규 저장에는 요청 ID를 사용하고, 수정에는 기대 버전을 사용합니다. 요청 재전송이나 동시 편집으로 정리본이 중복 생성되거나 이전 내용이 덮어써지지 않도록 처리했습니다.
- 브라우저 도구 2개는 화면의 선택 강의 조회와 검색을 사용합니다. 별도 Site MCP와는 다릅니다. 실제 WebMCP 컨텍스트 검증은 미실시입니다.
- 녹음 업로드·자동 전사·OpenAI 모델 API·Render 연결은 추가하지 않았습니다. 기존 `Hagyurid/study`는 수정하지 않았습니다.

## 검증 결과

| 종류 | 실행 결과 | 한계 |
|---|---|---|
| Node 도메인·HTTP·리포지토리·MCP·Sites 어댑터 테스트 | 38개 통과 | Node SQLite 및 R2 테스트 더블 |
| JavaScript 구문 검사 | 통과 | 실행·브라우저 검증과 별개 |
| TypeScript 검사 | 통과 | 런타임 검증과 별개 |
| 공식 Sites 빌드 | 통과 | 운영 배포 완료를 의미하지 않음 |
| 빌드된 Worker 통합 검사 | 10개 통과 | workerd/Miniflare의 로컬 D1·R2. 로그인 헤더는 테스트에서 주입 |
| 내부 D1 스키마 적용 | 28개 SQL 문 적용 성공 | 로컬 에뮬레이션만 적용, 운영 DB 미확인 |
| 브라우저 클릭·모바일·실제 OAuth | 미실시 | 통과로 표시하지 않음 |

재현 명령:

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm test
pnpm run typecheck
pnpm run build
pnpm run test:worker
```

Worker 검사는 영구 저장 없이 새 로컬 D1/R2로 실행하고 마지막에 폐기합니다. CI에도 동일한 검사 흐름을 추가했습니다. GitHub Actions의 원격 실행 결과는 해당 실행이 끝난 후 별도 확인해야 합니다.

## 승인 후 진행할 순서

1. 저장한 동일 버전을 **본인만 접속하는 자료 변경 잠금 상태**로 첫 배포합니다. 공개 범위를 확대하지 않습니다.
2. 실제 ChatGPT 로그인, 로그아웃, 미로그인 요청의 거부, D1 초기화와 R2 바인딩을 확인합니다. 플랫폼 서비스 접근이 사용자 신원을 대신하지 않는지 확인합니다.
3. 서버 인증 경계가 확인된 후에만 자료 변경 잠금을 해제하고 과목 등록 → TXT 업로드·검색 → PDF 원본 다운로드 → 정리본 저장·수정 충돌을 실제 사이트에서 검증합니다. 테스트 자료는 정리하고 빈 서비스로 시작합니다.
4. 이후 PDF 페이지 추출, 과목 정보 편집, 버전 복원, 작업 상태/재개 UI를 완성합니다.
5. 마지막으로 Site MCP 기능을 켜고 Sites가 제공하는 전용 플러그인을 연결합니다. 기존 `plugin/skills/`와 `docs/GPT_WORKFLOW.md` 규칙을 유지하고 실제 ChatGPT 읽기·쓰기 및 저장 결과를 검증합니다.

사용자에게 지금 필요한 결정은 첫 **본인 전용·자료 변경 잠금 배포**의 승인입니다. 모델 API 키나 Render 설정은 필요하지 않습니다.
