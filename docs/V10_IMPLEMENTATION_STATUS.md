# 에쁠가속기 v0.10 검토 기록 — 2026-10-09

## 구현된 소스

- Site MCP 기능 선언 및 인증된 `POST /mcp`. 과목 중심 도구만 광고하며 서버에서 소유권·쓰기 역할을 다시 검사한다. 운영 `APLUS_WRITES_ENABLED=false`이면 쓰기 도구도 잠긴다.
- PDF.js를 사이트에 포함. 업로드 후 브라우저에서 한 페이지씩 렌더링한 JPEG와 텍스트 추출본을 과목/자료/페이지에 귀속한다. R2에는 원본과 페이지 이미지를, D1에는 페이지 수·이미지 키·추출 문자열을 저장한다. 일시정지와 이어하기를 지원한다.
- GPT는 원본 페이지 이미지나 TXT/MD 전사 원문을 읽고 `raw_text`, `corrected_text`, `evidence_ids`, `unresolved`를 분리 저장한다. PDF는 선언된 페이지 수와 모든 이미지·교정 페이지가 맞아야 검토 완료가 된다. 생성은 검토 완료본만 선택한다.
- SolvePad는 iframe/로컬 전용 도구 대신 현재 사이트의 문제 목록·수식 표시·답안·힌트·해설·펜/지우개·필기장·되돌리기·오답·북마크 UI를 사용한다. 문제별 풀이를 현재 로그인 사용자의 D1 레코드에 저장한다. 구 도구 정적 페이지는 제거했다.
- 기존 Study Note 팝업과 CASIO iframe도 제거했다. 현재 사이트 자체의 정리본 원문 편집·보기·인쇄 및 CASIO Blueprint/PRGM/설명서 저장을 사용한다.

## 별도로 확인해야 하는 것

- 업로드 시 ChatGPT가 자동 실행되지는 않는다. 사용자 대화에서 플러그인을 연결하고 OCR/전사본 검토를 시작해야 한다.
- PDF 페이지 수는 브라우저 PDF.js가 보고한 값을 저장한다. 서버가 PDF 바이트를 독립 파싱해 페이지 수를 증명하는 기능은 아직 없다.
- 손글씨·수식·표의 GPT 판독은 오류 가능성이 있으며 미확인 항목은 검토 대기 상태로 남는다.
- 실제 ChatGPT 플러그인 설치, 이미지 응답 수신, 교정본 쓰기와 기기별 펜 입력은 사이트 게시 후 실사용 검증이 필요하다. 자동 테스트 통과를 실사용 검증으로 표시하지 않는다.
- DOCX/PPTX의 본문 추출, Word 내보내기, CASIO 코드 실행·검증·ZIP은 제공하지 않는다.
- 이전 v0.9의 과목 자료가 비어 있다면 백업/이관은 진행하지 않는다. Render 데이터는 이전하지 않는다.
