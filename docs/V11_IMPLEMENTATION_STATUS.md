# 에쁠가속기 v0.11 검토 기록 — 2026-10-09

## 구현

- 사이트의 MCP 서버는 Sites 인증 사용자로 과목별 읽기·쓰기 권한을 검사한다. 연결된 ChatGPT 플러그인의 원본·검토본·생성·이어하기 도구만 노출한다. 기존 제공 도구의 레거시 MCP 항목은 노출 목록과 코드에서 제거했다.
- `save_course_outline`의 입력 형식을 `{title}` 객체 배열로 고쳤다. `list_course_jobs`, `get_course_generation_progress`와 사이트의 작업 목록·이어하기 요청문을 추가했다. 제목과 자료 ID를 고정하고 이미 저장한 절부터 이어갈 수 있다.
- 긴 전사본·PDF 문자 추출본·교정본은 페이지와 문자 구간으로 나눠 읽는다. `page_count`, `total_chars`, `next_offset`을 반환한다. PDF 페이지 이미지는 R2의 실제 PNG/JPEG 바이트를 MCP 이미지로 반환한다.
- `course_document_versions` 마이그레이션을 추가했다. 새 정리본과 수정본, GPT 목차 및 절별 자동 저장이 버전 이력에 남는다. 기존 문서는 마이그레이션 시점의 현재 판본만 보존한다. 수정 시 revision 충돌을 검사하고 GPT 자동 저장도 사용자의 수동 편집을 덮어쓰지 않는다. 정리본 재전송에는 요청 ID를 사용한다.
- 정리본 화면에서 불러오기와 새 문서 선택 시 바로 편집기를 열고, 이전 버전을 가져와 새 판본으로 저장할 수 있다. 안전한 DOM 기반 Markdown 미리보기로 제목·목록·표·코드·형광펜·수식을 보여준다. PDF 인쇄는 브라우저 인쇄 기능을 이용한다.
- SolvePad는 사이트 자체의 문제·답안·힌트·해설·필기·오답·북마크로 동작하며 개인별 D1 풀이를 저장한다. 구 iframe과 정적 도구 페이지는 제거됐다.

## 검증

- `npm run check`, `npm test`(14개 테스트 파일), `npm run lint`, `npm run typecheck`, Sites 빌드, `npm run test:worker`(12개 Worker 검사) 통과. 로컬 Workerd에서 시험용 Sites 인증 헤더와 D1/R2 에뮬레이션으로 MCP 이미지, 전사본 교정, 목차·절 저장, 버전 이력, 타 사용자 차단을 확인했다. 기존 데이터가 있는 D1에서 버전 테이블로 현재 판본을 옮기는 마이그레이션도 검사했다.
- 설치된 플러그인을 운영 사이트에 연결해 도구 호출이 서버에 도달하는 것을 확인했다. 운영 D1에는 사용자의 과목·자료가 아직 없으므로 실제 교정본 쓰기와 PDF 이미지 읽기는 수행할 대상이 없다. 없는 ID에 대한 자료 목록 호출은 Not found로 거절됐다. 이를 저장 성공으로 표시하지 않는다.
- 로그인 상태의 사이트 사용과 iPad·휴대폰 펜 조작은 사용자가 직접 확인한다. 브라우저/기기 실사용 검사를 자동 테스트로 대신 표시하지 않는다.

## 제한

- 업로드 직후 AI OCR 자동 실행은 없다. ChatGPT 대화에서 플러그인에 검토를 요청해야 한다.
- 손글씨·수식·표 판독은 모델의 오류 가능성이 있어 검토와 미확인 표시가 필요하다.
- PDF 페이지 수는 브라우저 PDF.js에서 읽으며 서버 독립 파싱은 없다.
- DOCX/PPTX 본문 추출, Word 내보내기, CASIO 코드 실행·기종 검증·ZIP은 제공하지 않는다.
- Render 데이터 이전, 별도 OpenAI API 키, 음성 업로드·자동 전사는 없다.
