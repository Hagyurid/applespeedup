# ChatGPT Work / @Sites 인계 지시서

## 사이트 이름
**에쁠가속기** (A+ Accelerator)

## 필수 조건
1. 기존 `study` 저장소의 main, 기존 Render 운영 서버를 변경하지 않는다.
2. OpenAI API를 호출하는 웹사이트 기능은 추가하지 않는다. AI는 ChatGPT 안에서만 실행한다.
3. 녹음 파일 기능은 제외. 사용자가 TXT/MD, 추후 DOCX 형태의 **전사본 텍스트**를 등록한다.
4. `web/` 정적 프로토타입을 기준으로 Sites에 맞게 구현한다. 로컬 IndexedDB는 시연용이며, D1/R2로 전환할 때 공통 리포지토리 인터페이스를 유지한다.
5. Sites에 D1/R2 연결이 실제로 가능한지, 파일 업로드/조회/삭제가 가능한지 확인한다.
6. `sites/schema.sql`에 정의된 핵심 테이블과 인덱스를 순서대로 설치한다. 인증 사용자별 `course_members` 권한을 실제로 검사한다.
7. `sites/mcp-core.mjs`의 9개 도구 계약과 `sites/repository.mjs` D1 접근 계층을 기반으로 실제 사이트 환경에 맞는 MCP HTTP transport를 구현하고, 사이트 소유자가 플러그인을 게시·설치한다.
8. 사이트가 저장된 강의 자료를 ChatGPT에서 검색하고 `save_note`로 정리본을 저장할 수 있는지 End-to-End 검증한다.
9. 각 학년도 자료를 엄격히 구분하고 과거 기출은 스타일 참조로만 활용한다.
10. 필수 기능의 호환성·접근제어 검증 완료 전까지 '배포 완료'라고 보고하지 않는다.

## Sites 초반에 확인할 항목
- 이 계정에 Site 생성/게시 기능이 제공되는가?
- D1/R2가 활성화되어 있고 쓰기 권한이 있는가?
- 로그인한 사이트 방문자의 인증 식별자를 안전하게 구할 수 있는가?
- 배포 시 동일 사이트의 MCP 서버를 연결할 수 있는가? 도구 읽기/쓰기 승인 동작은?
- 파일 최대 크기와 파일 추출(특히 PDF/DOCX) 라이브러리 제한은 무엇인가?
- 초대된 친구가 데이터베이스를 읽고 쓰도록 할 수 있는가? 전용 사용자 계정이 가능한가?

## 실제 완료해야 할 스모크 테스트
1. 2026-2 촉매반응공학 과목과 2025-2 과거 개설 강의를 만들고 각기 다른 기출/강의자료 등록.
2. 전사본(TXT)을 업로드하고 D1에서 관련 청크가 검색되는지 확인.
3. ChatGPT에서 '2026-2 5주차 목차 생성' 요청. MCP `get_course_context` → `list_sources` → `search_source_content` 호출 확인.
4. `save_note` 수행 후 웹사이트 정리본 목록에 표시되는지 확인.
5. 정리본 수정 시 기대 revision이 다르면 충돌을 보고해 덮어쓰지 않음.
6. 타 계정의 source_id로 조회하면 서버에서 거부.
7. Render 없이 Site가 단독으로 동작한다는 증거 확보.
