# 기존 「시험 대비 자료 생성 프롬프트.xlsx」 적용 내용

원본 엑셀의 17행 구성과 주요 제작 시나리오를 직접 살펴보고 적용했다. 파일은 현재 프로젝트 공개 소스에는 넣지 않음(민감한 사용자 맞춤 지침을 GitHub 공개 브랜치로 옮기지 않기 위해).

| 엑셀 시나리오 | 신규 모드 또는 기능 | 중요 규칙 |
|---|---|---|
| 요약 PDF LaTeX (2 column) | `subnote` | 왼쪽 학습 내용 + 오른쪽 필기 여백; 인쇄와 본문 생성 분리 |
| 중요 목차·집중 포인트 | `outline` | 주차·단원·원본 페이지·확인 필요 범위 |
| 교수 시험 경향 분석 | `exam_trends` | 실제 기출과 추정 분리, 학년도/교수 필터 |
| 과목별 프로젝트 지침 | 과목 프로필 + 생산 프리셋 | 암기/수식/도식/화학 구조 특성 |
| 노트북LM 슬라이드 | 차기 출력 엔진 | 시각 콘텐츠·흑백 슬라이드 템플릿, PDF 검증 필요 |
| 녹음 전사 정리 | `transcript_fix` | 변경: 사용자가 이미 전사된 TXT/MD·붙여넣기 자료 등록, 음성 처리 없음 |
| 시험형 문제집 | `exam_paper` | 문제지·간단 답지·상세 해설 구분; 계산 문제는 단위·오차 확인 |
| 시험 직전 자료 | `exam_cram` | 중요 근거·핵심 요약·수식 가정 |
| 오답노트 | `errors` | 실제 답안과 오류 분석, 재발 방지 |
| 수식 교체·OMML·오개념 | 다음 버전 품질 검사 | 웹 수식↔LaTeX↔Word OMML 일치 검사 |

일부 기존 프롬프트의 '모든 수식을 $$로' 같은 규칙은 웹 편집·Word OMML 변환과 충돌할 수 있어 **콘텐츠 규칙/표현 규칙/출력 규칙**으로 분리.
