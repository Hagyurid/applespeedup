# 에쁠가속기 v0.9 통합 개발 현황 — 2026-10-09

> 이 문서는 v0.9 당시 상태 기록이다. 현재 구현·배포 상태는 [V10_IMPLEMENTATION_STATUS.md](V10_IMPLEMENTATION_STATUS.md)를 본다.

기준 브랜치: `Hagyurid/applespeedup / develop/aplus-v2`. 기존 `Hagyurid/study`는 읽기 전용이며 Render 자료 이전은 하지 않음.

## 반영된 코드

1. **전역 과목 선택** — 6개 페이지(과목 / 강의자료 / GPT 제작실 / 정리본 / SolvePad / CASIO) 공통. 과목 전환 시 체크한 자료 초기화.
2. **과목 중심 D1** — `drizzle/0004_course_library.sql` 및 `sites/course-v2.mjs`: 과목에 자료·노트·문제팩·개인 풀이·CASIO·생성 작업을 직접 귀속. 구 `offerings`를 새 자료 등록에서 만들지 않는다. 구 테이블은 이전 코드와 테스트 호환을 위해 유지.
3. **자료 등록** — 사용자가 입력한 제목/과목/유형 우선. 일반 자료는 1~30주차 복수 선택 가능, 기출은 주차 대신 연도 단일 선택. PDF/PNG/JPG/DOCX/PPTX와 전사된 TXT/MD를 보관. 최초 상태는 `pending_review`.
4. **GPT 자료 선택** — GPT 제작실 오른쪽에 과목별 파일 체크, 주차/기출연도 그룹 선택, 개별 선택·해제 및 필터. 모든 페이지 검토 저장 후 선택 가능(`reviewed` 또는 `reviewed_with_issues`). 불명확 항목은 제작 시 함께 전달.
5. **교정본만 모델에 제공** — `get_course_verified_text`/ `/api/v2/reviewed`에서 확인된 페이지 `corrected_text`만 읽음. PDF 원본이나 미확인 OCR을 생성 원문으로 제공하지 않음. 자료 등록창에는 사용자용 GPT 검토 요청 복사 기능 추가.
6. **목차/구조 선저장과 자동 저장** — `start_course_generation` → `save_course_outline` → `save_course_part`. 목차가 없으면 본문 작성 차단. 각 파트의 저장은 같은 노트의 자동 갱신으로 연결.
7. **Study Note** — 정리본 읽기/원문 편집, 브라우저 PDF 인쇄, 기존 고급 편집기 팝업과 사이트 저장 브리지. 고급 편집기의 MathJax·표·형광펜·이미지 기능은 레거시 코드이며 새 서버의 슬라이드 이미지 API/Word 엔진은 미연동.
8. **SolvePad** — 레거시 펜·문제풀이·오답 UI, 새 과목 문제팩 목록/JSON 등록 및 iframe 불러오기, 서버에 개인 필기·진행·북마크 기록 저장. 구 레거시 전용 원격 서버 API는 완전히 대체되지 않음.
9. **CASIO** — 과목별 프로젝트 목록, Blueprint/PRGM/설명서 읽기·저장, TXT 다운로드. 기존 CASIO 편집기는 별도 접이식 화면에서 볼 수 있으나, 과거 Render 기반 유효성 검사·코드 생성·ZIP 기능은 미이식.
10. **사용자 인증** — Site 로그인 헤더와 과목별 권한을 서버에서 재검증. 읽기/쓰기 별도 역할. 교정본 미완성은 생성에 사용 불가.

## PDF 자동 OCR: 정확한 제약

- **PDF 업로드 순간에 자동으로 ChatGPT가 모델 실행을 시작하는 동작은 제공되지 않는다.** 별도 모델 API/상시 AI 작업 없이 업로드 이벤트에서 ChatGPT를 호출할 수 없다.
- PDF 원본은 저장·대기 상태로 표시된다. 이미지 파일 PNG/JPG에 대해서는 `get_course_page_image`로 ChatGPT에 원본 이미지 전달하는 경로를 마련했다.
- **PDF를 페이지별 이미지로 변환해 MCP가 읽는 연동은 아직 미완료**. 따라서 PDF 등록 후 GPT OCR 자동 완료를 주장하지 않는다.
- GPT 대화에서 검토 작업을 실행할 때 모델이 실제 원본에 접근하는 것이 필요하다. 검토한 내용이 `save_course_review_page`로 원문/교정본/근거/불확실성 분리 저장되고 모든 페이지의 검토 저장이 끝난 경우만 자료 제작실에서 선택 가능하다.
- ChatGPT 모델 OCR의 수식·화학식·손글씨 인식에는 오류 가능성이 있다. 미확인 항목을 0이라고 강제로 만들지 않고 교차 검증·사람 확인 필요 상태로 남긴다.

## 실제 Sites 릴리스 조건

- 현재 `sites/runtime.mjs`는 안전상 `/mcp`를 **503 비활성** 상태로 유지하고, `APLUS_WRITES_ENABLED` 기본값은 false.
- 새 D1 마이그레이션 0004를 실제 Sites 배포에 적용하고 기존 사용자 로그인·과목 저장·R2 업로드·읽기·쓰기·권한을 실제로 검증해야 한다.
- Plugin/Skill 실제 설치와 이미지/교정본 읽기, 선목차, 절 자동 저장 E2E 테스트가 미완료.
- 새 프로젝트 내부 백업/복원은 별도로 구현 필요. 과거 Render 자료 백업·이전은 진행하지 않는다.
- PDF 페이지 래스터화, CASIO 검증·ZIP, 노트 Word(.docx), SolvePad의 모든 레거시 서버 연동은 아직 미완료.
