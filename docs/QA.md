# QA 및 출시 차단 기준

## 자동 테스트
- 과목·학년도·교수별 독립성
- 올해 자료 우선, 기출은 출제 경향으로만 활용
- TXT/MD 전사 텍스트 분할·검색 범위 유지
- 잘못된 빈 정리본·초기화되지 않은 Offering 거부
- GPT 요청 생성 시 source_id, offering_id 누락 방지
- MCP 미인증자 도구 접근 금지, 존재하지 않는 도구 호출 거부
- DB 장애 오류 메시지에서 비밀값/경로 누출 금지
- 작업 체크포인트 단계 재개 검사
- HTML 콘텐츠 출력 XSS 인코딩

## 브라우저 시나리오
- PC 1440px, 태블릿 810px, 모바일 390px에서 메뉴·폼 정상 작동
- 새 과목 → 과거/현재 강의 등록 → 전사본 입력 → 검색 → GPT 요청 복사 → 정리본 생성/수정 → 백업
- 재시작 후 데이터 유실 없음, 백업 JSON은 중요한 사용자 데이터 밖으로 자동 업로드하지 않음
- 다중 클릭·두 탭 동시 편집·네트워크 실패에서 중복 생성·덮어쓰기 방지
